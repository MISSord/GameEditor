# ACT 角色选型与招式包模板（单手刀 / 单手剑）

> 状态：**选型结论 + 模板规范，未开工**。做新角色（玩家侧）前先读本文，按 §五 模板逐项填表。
> 关联：`ActCombatRoadmap.md`（M1 失衡 / M2 招架 / M5 喧响，新角色招式是这些系统的落点）、`ActSkillConfigAndLeveling.md`（段表与升级）、`ActEnemyAiDesign.md`（12000 号段隔离策略）、`ProjectConventions.md`（轴/配表硬约定）。
> 养成（等级/命座/装备）不在本文，按项目约定后置。

## 一、选型原则（框架能力圈）

新角色招式必须落在框架"容易表达"的范围内，不引入新系统：

| 能力 | 现状 | 结论 |
|---|---|---|
| 普攻连段 + 连招窗 | ✅ 11001–11003 | 可用 |
| 战技多段 + HitGroup | ✅ 段表 `(SkillId, SegmentIndex)` | 可用 |
| 位移斩 / 突进 | ✅ `MotionDirector` SkillCurve / RootMotion（12002 已验证） | 可用 |
| 极限闪避 + 断裂 | ✅ 已落地 | 可用（零改造） |
| 大招 + 时停演出 | ✅ `UltimateCinematic` 包 | 可用 |
| 形态切换 | ✅ `CombatFormComponent` 基础版 | 可用（漂泊者可把形态推到可用级） |
| 被动强化 | ✅ `PassiveSkillBuffComponent` | 可用 |
| 分支技 | 🟡 `SkillDefine` 有概念、未铺开 | 后置 |
| 弹道 / 剑雨 / 锁头飞弹 | ❌ 未做 | **禁用**：大招剑气一律做近身范围段 |
| 空中连段 | 🟡 跳跃有、空战弱 | **禁用**：不做空战型角色 |
| 命中华丽粒子 | 🟡 HitParticle 桥未接 | 特效先做简化版 |

**铁律**：近战多段 + 位移型战技 + 范围型大招；"剑雨、飞剑、空战、召唤物"全部排除。

## 三、逐角色招式映射

### 3.1 鸣潮·漂泊者（正式首选）

| 招式 | 框架映射 | 实现要点 |
|---|---|---|
| 普攻 4–5 段连斩 | `13001–13004` 连招链 + 连招窗 | 节奏对齐现有 11001–03 手感 |
| 重击蓄力斩 | 段表单段重击 → `HitCausedHeavy` 包 | 蓄力=前摇长，段号 ≥ 2 |
| 共鸣技能：突进斩 | 战技槽位 + 轴上 SkillCurve 位移 | 照抄 12002 突进写法，`UseRootMotion: 0` |
| 共鸣解放：剑气范围斩 | 大招槽位 + `UltimateCinematic` 时停 | 剑气 = 近身扇形多段盒，**不做飞弹** |
| 光 / 暗双属性 | `CombatFormComponent` 切形态换段表 | 验收形态系统；配表按 Form 分槽位 |
| 极限闪避 | 现有断裂 + 灰屏 + 残影 | 零改造 |

**为什么首选**：项目全程对照鸣潮，动画风格 / 受击节奏 / 顿帧参数同源，成品味最正。

### 3.2 战双·露西亚（红莲 / 黎明，单手刀味最正）

| 招式 | 框架映射 | 实现要点 |
|---|---|---|
| 普攻刀光连段 | `1310x` 连段，轻快节奏 | 段与段间隔短 |
| 三消球 → 三战技变体 | **裁剪**：不做球色经济，取黄=位移斩 / 红=强化斩 / 蓝=短状态，做三个独立战技轴 | 槽位表天然支持多战技 |
| 大招：剑气大范围斩 | 大招 + 时停，近身范围段 | 范围盒可扇形 180° |
| 闪避 → 超算空间 | 直接复用 `DodgeTimeFracture` | 战双是库洛的，与项目断裂同源，零改造 |

### 3.3 绝区零·零号安比（验证首选）

| 招式 | 框架映射 | 实现要点 |
|---|---|---|
| 普攻 3–4 段快速斩 | 复用现有 11000 结构 | 最小改动 |
| 特殊技：突刺 | 战技单段 + SkillCurve 位移 | 单段即可 |
| EX 特殊技强化 | 段表加段 + 更重表现包 | 段号 ≥ 2 走重顿 |
| 大招：电刃范围斩 | 大招 + 时停 | 近身范围段 |

**为什么先做她**：招式数最少、全是"段 + 位移 + 大招"三件套，用于跑通 §五 完整流水线；且她是 ZZZ 角色，M1 失衡 / M2 招架落地后她的招式正好当验收样本。

### 3.4 原神·刻晴（位移压测）

| 招式 | 框架映射 | 实现要点 |
|---|---|---|
| 普攻 5 段 | 连段链 | 无压力 |
| E 星斗归位（投雷楔 + 二段瞬移） | 技能轴双段：一段投掷标记、二段瞬移到标记点 | 瞬移 = 无碰撞位移，`MotionDirector` 位移通道压测 |
| 重击：突进刺 | 重击段 + SkillCurve | 常规 |
| Q 天街巡游：多段范围雷剑 | 段表多段 + HitGroup（一刀一段号） | 密集命中下飘字聚簇 / 表现包压测 |
| 雷附魔被动 | `PassiveSkillBuffComponent` | 现成 |

### 3.5 备选：崩坏3·雷电芽衣

分支攻击（长按 / 条件触发分支连段）对应框架未铺开的"分支技能"。等漂泊者形态稳定后再考虑，示范 `SkillDefine` 分支概念。

## 四、落地顺序（新角色流水线）

| 步 | 角色 | 目的 |
|---|---|---|
| 1 | **安比**（最小招式包） | 跑通新角色全流程，验证框架复用性 |
| 2 | **漂泊者**（正式角色） | 光/暗形态把 `CombatFormComponent` 推到可用；风格与项目主线一致 |
| 3 | **露西亚·红莲**（可选第二角色） | 三战技变体 + 大范围剑气大招，验证多技能槽与演出上限 |
| 4 | **刻晴**（可选实验） | E 瞬移 + 大招多段，压测位移通道与段表 |

**段号规划**：玩家新角色统一走 `13xxx` 段（11000=现有玩家段、12000=敌人段、13000=新角色段），每个角色一个号段（漂泊者 130xx、露西亚 131xx……），配表 / 轴 / 表现包按号段隔离，与敌人 12000 的分离策略一致。

## 五、新角色招式包模板（核心，做角色照此逐项填）

### 5.1 开工前清单

- [ ] 段号申请（13xxx 起，不与 11/12 冲突）
- [ ] 槽位表（§5.2）
- [ ] 段表行（§5.3）
- [ ] 技能轴（§5.4，只改 `Assets/Editor/SkillSequences/{SkillId}.prefab` 再 Flux 导出，禁止手改 `SkillDataScriptable`）
- [ ] 表现包（§5.5）
- [ ] 手感参数（§5.6）
- [ ] 打断 / 抗打断数值（§5.7）
- [ ] 新角色验收（§5.8）

### 5.2 槽位表（`SkillSlotConfig` / `SkillFormConfig`）

| 槽位 | Sort | 技能 | 说明 |
|---|---|---|---|
| 普攻 | Normal（连招链 1→2→3→…） | 13001… | 连招窗追加 |
| 战技 | 战技 Sort | 13010（多战技可 13011/13012 变体） | 可带位移段 |
| 闪避 | Roll | 复用现有翻滚 | 极限闪避自动断裂 |
| 大招 | Ultimate | 13020 | `UltimateCinematic` 时停演出 |
| 被动 | 常驻 Buff | `PassiveSkillBuffComponent` 挂接 | 不进技能轴 |
| 形态（可选） | Form | 换段表 / 换槽位表 | 漂泊者光/暗用 |

### 5.3 段表（`SkillDamageSetting`，一行一刀）

| 字段 | 要求 |
|---|---|
| 主键 `(SkillId, SegmentIndex)` | 段号 ≥ 1，编辑器默认 1 |
| `DamageType / FormulaType / CanCrit` | 按招定 |
| `RatioByLevel` | `1.0\|1.08\|...` 逐级数组，短了用最后一档 |
| `HitReactionType` | 轻 / 重 / 失衡分级（§六·4 路线图） |
| 未来列 | `DazeValue`（失衡贡献，M1）、`AnomalyType/Value`（异常积蓄，M3）——现在留空 |

### 5.4 技能轴结构（每个轴的必备轨）

| 轨 | 内容 | 规则 |
|---|---|---|
| 动画轨 | 攻击 / 前摇 / 后摇 | 新角色先借用现有剪辑对位 |
| 位移轨 | MoveEvent / 曲线位移 | 带曲线的招必须 `UseRootMotion: 0`（`MotionDirector` 水平通道互斥） |
| Trigger 轨 | 段号 ≥ 1、HitGroup（一刀多盒同段同组） | 空 EffectIds = 只出该段伤害 |
| Tag 轨 | 霸体段推 `Buff.UnStopped`（+3，不是免疫） | 玩家出招窗抗打断按 §5.7 配 |
| 表现消息轨 | `HitCaused*` 包、音效、相机意图（`CameraIntent(SkillCamera)` 演出） | 大招推时停包 |
| 收招轨 | 连招窗 / `IsMainFinish` | 连段追加点 |

### 5.5 表现包清单

| 包 | 内容 | 复用 |
|---|---|---|
| 轻/重/暴击命中 | HitStop + 震屏（Light/Heavy/Crit 档）+ 闪白 + CA/RadialBlur | 已有 |
| 大招演出 | `UltimateCinematic`（时停）+ 相机意图 + 刀光特效 | 已有 |
| 位移拖尾 / 刀光 | 粒子桥未接，先做简化版或轴上粒子事件 | 简化 |
| 音效 | 轴上 PlayAudio | 已有 |

### 5.6 手感参数

- 顿帧：段 1 轻（0.08s）、段 ≥2 重（0.14s）、暴击更重、大招特档；
- 震屏：`CameraShakeProfile` 轻/重/暴击档，位移从 0.04–0.14m 起调；
- 相机：入场 / 大招用 `CameraIntent`（SkillCamera 源，带时长自动归还）。

### 5.7 打断 / 抗打断（`CombatInterrupt` + `CombatPoiseComponent`）

- 玩家站立抗打断 1；出招段可推 `Buff.UnStopped`（+3）；
- 段表 `InterruptLevel`：Light=0、Heavy 回退=3、大招段可按 5 配（能破杂兵霸体 1+3=4，破不了精英出招窗 6）；
- 硬控无视抗打断（沿用现有约定）。

### 5.8 新角色验收清单

- [ ] 普攻连段手感与 11001–03 一致，连招窗不误触发
- [ ] 战技位移与 `MotionDirector` 通道无冲突（曲线招无 RootMotion）
- [ ] 大招时停期间世界慢、自己轴不停（SkillTimeStop hold）
- [ ] 极限闪避 + 断裂 + 灰屏 + 残影全兼容
- [ ] 打断比大小正确（打杂兵 / 精英分别验证）
- [ ] 飘字聚簇 / 暴击染色在多段命中下不重叠错乱
- [ ] 锁定 + 相机意图（入场 / 大招）接管与归还平滑
- [ ] 形态切换（如有）：换段表、轴不残留、Buff 按 Form 生命周期清理

## 六、注意事项

1. **动画资产**：招式设计可参考，动画不得从游戏提取（版权）。起步沿用"借用现有剪辑 + 对位"，后续用动画商店刀剑动作包替换（与 `ActCombatRoadmap.md` §六·2 敌人动画同源思路）。
2. **弹幕裁剪**：漂泊者剑气、刻晴雷剑一律做近身范围段 + 刀光特效，不碰锁头飞弹（未做）。
3. **养成后置**：等级/命座/装备不参与招式包设计；段表 `RatioByLevel` 只留升级口。
