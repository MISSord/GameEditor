## 三、黄闪招架（弹招 / 极限支援）（P0）

### 3.1 目标

补全攻防三角的"挡"：敌人黄闪招式**可被招架**，成功招架 = 打断或重硬直 + 全场 Relax（回合让出）；红闪仍必须闪。招架成功给偏谐条加值。只学绝区零黄红闪，**不做鸣潮收缩金圈弹刀**（已拍板）。

### 3.2 框架与结构

学绝区零**防御支援 / 极限支援**的撞刃拍，不是凯撒式站桩格挡，也不是鸣潮金圈弹刀。

- 招式身份：`EnemyMoveSet.TelegraphKind = Parry` 的黄闪招；判定窗在来刀上（Enqueue 开窗，轴上 `Ai.Parryable` / `Ai.ParryBreak`）。
- 玩家 11005 只是**成交后的振刀演出**，不是窗口本身。轴必须短（约 16～20 帧 @30fps，0.5～0.7s），无盒、无 RootMotion。
- 成功结算：吸附到刀路 → 短世界断裂 + HitStop → 敌人断轴进 **Stun 硬直（盖住 11005 + 余量）** → 导演 Relax 同步该时长 → 偏谐贡献。
- 失败：没黄窗按 L 不成交；黄闪漏了按普通受击，不做额外惩罚。

### 3.3 撞刃时间轴（双方动画）

绝区零这一拍是**共享节拍**：世界先顿，角色瞬移贴刃，敌人停在被格的姿态/硬直里，玩家播短振刀，敌人比玩家晚一拍才能动。

```
t=0      黄闪来刀，玩家按 L
         吸附到身前 1.35m，双方对向
         TimeFracture ~0.32s（世界慢、玩家轴仍走玩家钟）+ HitStop + 闪白 + 重震
t=0～P   玩家 11005 振刀（目标 P≈0.55s）
         敌人 Stun 硬直，不回 Idle、不走进攻
t=P      玩家交回 Locomotion，可出招惩罚
t=P+0.28 敌人才结束 Hit，Brain 才 Approach
```

禁止：断轴后播短 `Damage` 再自动 `ForceLocomotion`（会立刻 Idle）；Relax 只跟完美闪 0.45s（敌人会在振刀中途恢复进攻）。

动画资产规划：

| 谁 | 现在 | 目标 |
|---|---|---|
| 玩家 11005 | `MeleeAttackOne` 0～72 帧（~2.4s）过长 | 短撞刃/格挡 pose，16～20 帧，`UseRootMotion=0` |
| 敌人被招架 | 短 Damage → Idle | Stun 保持到硬直结束；以后可换专用「被弹开」clip |
| 连闪多段 | 整段 `Ai.ParryBreak` | 中段只 `Ai.Parryable`，不断整轴 |

表现包 `ParrySuccess`：短断裂 + 顿帧 + 闪白 + 重震 + 玩家残影。灰屏留给闪避，不要和 Perfect Dodge 混。撞刃火花粒子待 Bridge / 美术。

### 3.4 接缝

- 玩家侧走既有 `Enqueue → Gate → Session → XC`；11005 只播演出。
- 敌人硬直走 `CombatStateDirector.Hit` + `PlayHeldControlReaction`，不问技能名。
- 导演 `NotifyPlayerParry(seconds)`，时长对齐敌人 Stun，不盖 Punish。

### 3.5 完成后的效果

- 黄=挡、红=闪、白=硬吃；
- 成交那一拍：贴刃 + 世界顿 + 敌人 Stun，玩家振刀播完敌人还没动；
- **验收**：黄闪可招架、红闪无效、漏窗正常受击、敌人不瞬切 Idle、11005 结束后敌人才恢复进攻。

| 步 | 内容 | 状态 |

| 1 | 黄闪敌招 + 来刀窗 + 11005 成交 | 已通 |

## 五、Boss 相位与屏外公平（P1/P2）

### 5.1 Boss 相位

- **结构**：Boss 档在敌人 AI 的第三档（`PhaseMask` 字段已预留，`PhaseIndex` 写死 0）；HP 阈值（如 70/40%）升相位，只升不降。
- **流程**：HP 越阈值 → 导演/Brain 通知 → 播放过渡轴（可复用时停表现包 `UltimateCinematic` 的时停语义）→ `PhaseIndex++` → 后续选招按新 `PhaseMask` 换招式池 → 新相位可增 `AllowMeleePlusSpecial`、更换保持距离与 Recover 参数。
- **效果**：Boss 战有阶段感，每个相位招式池/节奏不同；**验收**：阈值触发、过渡轴不被打断（或按设计可打断）、招式池确实切换、不进站位槽。

### 5.2 屏外公平

- **结构**：导演侧两条规则——屏外敌人**发牌硬禁**或 `OffscreenDelay`（回到屏内后延迟 X 秒才可出手，AI 文档 §12.1 P0 已列）；屏外持牌者显示**攻击方向指示器**（屏幕边缘箭头，ZZZ 同款）。
- **流程**：`IsOnScreen`（5%~95% 视口）为假 → 不授予真伤 Token / 延迟计时；恢复屏内 → 计时结束可重新竞拍。
- **接缝**：画幅判定在相机 Stage 2 落地后用真实画幅，不再依赖 `Camera.main` 粗判。
- **效果**：玩家永远不会被"看不见的怪"偷袭，屏幕边缘有明确威胁方向。

### 5.3 部位破坏（可选，挂在本节）

ZZZ 部分精英有部位破坏（破坏特定部位换弱点/硬直）。方案：精英身上挂 `PartBreakComponent`，部位 = 独立小计量（复用 §二 计量组件），破坏触发局部硬直或弱点增伤，表现走部位特效。**P2 可选，不做不影响主循环。**

## 六、表现与资源体系补全（P2）

### 6.1 Telegraph 正式资产

- 现状：占位四角星 + 颜色/时长已通（`CombatTelegraph.Shown` 事件已留、无人订阅）。
- 方案：订阅 `Shown` 事件播放正式特效（黄/红/青/暖白各自的特效 + 提示音），特效池复用 `RunTimePoolManager`；12001/12003 平劈改轴上 `AiTelegraph` 或 `TelegraphKind.None` 减噪声（AI 文档 §12.3 第 1 条）。
- 效果：前摇语言完整（视觉 + 听觉），玩家凭提示即可读招。

### 6.2 敌人正式动画

- 现状：借用玩家剪辑，动作与位移不对位。
- 方案：敌人专用 Animator 控制器 + 对位动画替换；动画资产上线后，`EnemyMoveSet` 的轴引用同步切换（12000 段轴只换资产不换结构）。
- 效果：杂兵/精英观感独立，前摇/位移/受击可读性上一个台阶。

### 6.3 喧响值（团队大招）与 EP（特殊技能量）

- 现状：有 `CheckIsHadEnoughEnergy` 接口、`ResourceAction`、`Ultimate` 槽位与 `UltimateCinematic` 包，但**没有完整资源条体系**。
- 方案（结构）：
  - **喧响值**：团队级计量（复用 §二 计量组件），由极限闪避/招架/以后的谐度破坏等"高光行为"增长；满条解锁大招，大招消耗整条。大招本身复用技能轴 + 时停演出包，**不新建技能运行时**。不要再把失衡连携当涨条来源。
  - **EP（特殊技能量）**：角色级计量，普攻/命中回复、特殊技消耗；消耗判定接现有 Gate（`AbilityActivationGate` 处查资源）。
  - 两条都做成**资源条 UI**（不是 Buff 图标），随伤害来源与 ActionPoint 增长。
- 效果：大招从"无成本技能"变"资源决策"；高光 → 喧响 → 大招。偏谐 F 落地后再绑来源（§一）。

### 6.4 受击反应分级表现

- 现状：`CombatHitReaction` 只做入口（闪白/顿帧按段表 `HitReactionType`），短硬直 0.35s 一刀切。
- 方案：`HitReactionType` 分级落地为表现差异——轻（原地小硬直）、重（后仰/退步）、击飞（浮空/击退 + 相机 Kick 增强）。原「失衡段」不再当 Stagger 专用；满条高潮见偏谐文档。分段表列配置，表现走 `CombatPresentationDirector`。
- 效果：不同段的"打中感"有层次，重击和击飞一眼可辨。

### 7.1 硬控互斥（Buff 已收口）

问 Tag，不写 `if (眩晕)`：带 `State.MoveForbid` 的 Buff（眩晕 20001、冻结 20601/20602）同一时刻只留一条。

- 免疫/抵抗之后、真正 `RequestAddStatus` 之前走 `HardControlMutex.Admit`。
- 新硬控 Priority ≥ 已有：旧的 `RemoveStatus(..., Replaced)`，新的落地。
- 新硬控 Priority 更低：本次 `Blocked`，不落地、不卸旧。
- 同 BuffId 仍走 `RepeatedAddition`（刷新/叠层）。
- 沉默只有 `SkillForbid`，可与硬控并存。
- 表：冻结 Priority=20，眩晕=10，所以冻结不会被 1 秒眩晕顶掉。

**验收：** 眩晕中上冻结 → 只剩冻结；冻结中上眩晕 → 仍冻结；不会双图标、不会 Stun+冰壳抢动作。
